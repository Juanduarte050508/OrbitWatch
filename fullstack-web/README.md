# 🌐 OrbitWatch — Dashboard Web

> Interface web completa do OrbitWatch com frontend responsivo e backend JavaScript.

## 📚 Disciplinas

- **Front-end Design** — Profa. Julia Assunção Silva
- **Web Development** — Profa. Julia Assunção Silva

## 🛠️ Tecnologias

- **HTML5** — Estrutura semântica do dashboard
- **CSS3** — Estilização com múltiplos temas (light, dark, galaxy)
- **JavaScript** — Lógica de interação, slideshow, alternância de temas

## 📁 Estrutura

```
fullstack-web/
├── index.html              # Página principal do dashboard
├── script.js               # Lógica JavaScript (temas, slideshow, interações)
├── css/
│   ├── reset.css           # Reset de estilos padrão
│   ├── standardStructure.css # Estrutura base do layout
│   ├── lightStyles.css     # Tema claro
│   ├── darkStyles.css      # Tema escuro
│   └── galaxyStyles.css    # Tema galaxy
└── images/
    ├── light-dark/         # Ícones e backgrounds dos temas
    └── slideshow/          # Imagens do slideshow orbital
```

## 🚀 Como Executar

1. Clone o repositório principal:
   ```bash
   git clone https://github.com/Juanduarte050508/OrbitWatch.git
   ```
2. Navegue até a pasta:
   ```bash
   cd OrbitWatch/fullstack-web
   ```
3. Abra o `index.html` no navegador ou use o Live Server do VS Code

## ✨ Funcionalidades

- Dashboard de monitoramento orbital com informações sobre detritos espaciais
- Alternância dinâmica entre 3 temas visuais (Light, Dark, Galaxy)
- Slideshow com imagens relacionadas ao contexto espacial
- Layout responsivo para diferentes tamanhos de tela
